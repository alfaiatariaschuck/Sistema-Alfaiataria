# Schuck Alfaiataria — Estratégia de Caixa (Out/2026 → Mar/2027)

Pacote para os agentes de IA da Schuck. Objetivo único: **gerar caixa e formar reserva** enquanto a camisaria dobra de tamanho.

## Arquivos
| Arquivo | Para quê |
|---|---|
| `AGENTS.md` | Instruções para os agentes: o que fazer, o que NUNCA fazer, quando alertar o Tales. **Ler primeiro.** |
| `estrategia.md` | Diagnóstico financeiro, as 4 regras de caixa e o plano da expansão. |
| `plano-mensal.md` | Etapas e metas de cada mês, de outubro a março. |
| `rotina-semanal.md` | Checklist de toda segunda-feira. |
| `dados/metricas.json` | KPIs com fórmula, meta mensal e gatilhos de alerta (legível por máquina). |
| `dados/premissas.json` | Todos os números usados, com a fonte de cada um. |
| `dados/Schuck_Fluxo_de_Caixa.xlsx` | Planilha com a projeção mensal e o acompanhamento semanal. |

## Fontes
Extratos BTG da conta PJ (jul, ago e set até 24/09/2026), relatório de categorias do sistema (set/26), relatório de camisas do sistema (ago e set/26) e informações do Tales em 27/09/2026.

## Dono
Tales Schuck. Toda decisão que mexe com dinheiro é dele. Os agentes medem, alertam e preparam.
